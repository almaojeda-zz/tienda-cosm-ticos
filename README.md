# GLOW BEAUTY 💗

Tienda online ficticia de maquillaje, skincare y accesorios de belleza. Proyecto educativo realizado con **HTML, CSS y JavaScript**.

## Cómo abrir el proyecto

1. Descargá y descomprimí `GLOW-BEAUTY.zip`.
2. Abrí la carpeta `GLOW-BEAUTY`.
3. Hacé doble clic en `index.html` para abrir la tienda en el navegador.
4. Para editar el código, podés abrir la carpeta con Visual Studio Code.

No necesita instalación ni servidor para probar las funciones principales. Se recomienda tener conexión a Internet para cargar las fotografías y las tipografías externas.

## Funcionalidades

- Catálogo de productos con imagen, nombre, categoría y precio.
- Categorías de maquillaje, skincare y accesorios.
- Búsqueda por nombre o descripción.
- Filtro por categoría y orden por precio o nombre.
- Carrito: agregar productos, cambiar cantidades y eliminar artículos.
- Cálculo automático del total en pesos argentinos.
- Mensajes de confirmación para las acciones.
- Lista de favoritos.
- Modo oscuro.
- Guardado del carrito, favoritos y tema con `localStorage`.
- Simulación de compra con formulario. No se procesan pagos reales.
- Diseño responsive para celulares, tablets y computadoras.

## Archivos

- `index.html`: estructura y contenido de la página.
- `style.css`: colores, tipografías, tarjetas, botones, distribución y adaptación a pantallas.
- `script.js`: catálogo, filtros, búsqueda, carrito, favoritos, modo oscuro y compra de demostración.

## Identidad visual

- **Nombre:** Glow Beauty.
- **Concepto:** una tienda de belleza delicada, moderna y luminosa.
- **Paleta:** rosa pastel, rosa viejo, crema y blanco.
- **Tipografías:** Playfair Display para títulos y DM Sans para textos.
- **Logo:** identificación tipográfica con una estrella como símbolo.

## Cómo utilizar la tienda

1. Entrá en la sección “Productos”.
2. Buscá un artículo o seleccioná una categoría.
3. Tocá el corazón para guardarlo en favoritos.
4. Tocá el botón `+` para agregarlo al carrito.
5. Abrí “Carrito” para aumentar o disminuir cantidades o eliminar productos.
6. Revisá el total y elegí “Finalizar compra” para probar el formulario de compra.

Los datos del carrito y los favoritos se conservan en el navegador mediante `localStorage`. Si se abre la tienda en otro navegador o dispositivo, los datos no se comparten.

## Uso de Inteligencia Artificial

Se utilizó una herramienta de Inteligencia Artificial como apoyo para proponer la identidad visual, organizar los archivos, generar una primera versión del código HTML, CSS y JavaScript, y explicar las funciones. El código debe ser revisado, probado y comprendido por el alumno antes de la entrega.

## Publicar con GitHub Pages

1. Creá un repositorio en GitHub, por ejemplo `glow-beauty`.
2. Subí `index.html`, `style.css`, `script.js`, `README.md` y la carpeta `img` (si agregás imágenes locales).
3. En el repositorio, entrá a **Settings → Pages**.
4. En “Build and deployment”, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
6. Esperá a que GitHub Pages publique el sitio. El enlace aparecerá en la misma sección de Pages.

## Importante

Los productos, precios e imágenes son ilustrativos. La tienda es una demostración escolar: no tiene stock real, backend ni cobros en línea.
